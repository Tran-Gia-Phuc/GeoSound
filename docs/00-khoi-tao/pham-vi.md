# Phạm vi

> Dùng để tránh phình phạm vi. Cập nhật khi nhóm chốt backlog phiên bản 1.

## Trong phạm vi — bước khởi tạo (hiện tại)

- Cấu trúc thư mục chuẩn cho docs, frontend, backend, tests.
- Tài liệu nền: tầm nhìn, phạm vi, quy ước, chỉ mục docs.
- Quy ước nhánh / commit / pull request.

## Trong phạm vi — phiên bản 1 (dự kiến, chưa chốt)

Sẽ bổ sung sau khi có danh sách chức năng. Gợi ý khung:

- Tài khoản / phân quyền (nếu cần)
- Các chức năng cốt lõi gắn với ý tưởng GeoSound
- Lưu trữ dữ liệu tối thiểu để demo
- Kiểm thử cho luồng chính

## Ngoài phạm vi (tạm thời)

- Chốt stack và scaffold ứng dụng (thuộc bước hiện thực).
- Đặc tả yêu cầu chi tiết, use case, mockup (thuộc `docs/01-yeu-cau/`).
- Thiết kế kiến trúc / CSDL / API (thuộc `docs/02-thiet-ke/`).
- CI/CD, hạ tầng production, tối ưu hiệu năng quy mô lớn — trừ khi đồ án yêu cầu rõ.
